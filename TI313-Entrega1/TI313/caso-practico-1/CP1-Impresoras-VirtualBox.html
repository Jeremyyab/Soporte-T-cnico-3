Caso Práctico 1 — Tecnologías de Impresión

Instalación, configuración, compartición y diagnóstico de impresoras en un entorno virtualizado con VirtualBox.

📋 Tipo: Desempeño ⏱ Duración: ~120 min en clase 👥 Grupos: 3–4 estudiantes 🔧 Herramienta: VirtualBox + Windows 10 📷 Evidencia: capturas de pantalla obligatorias

📌 Descripción del caso

La empresa TechSopEx S.A. cuenta con una pequeña oficina de 3 computadoras. Recientemente adquirieron una impresora HP LaserJet y necesitan que todos los equipos puedan imprimir desde la red. El equipo técnico debe instalar, configurar y compartir la impresora correctamente, además de documentar un procedimiento de diagnóstico ante una falla simulada.

El ambiente de trabajo será completamente virtualizado usando Oracle VirtualBox con dos máquinas virtuales Windows 10 conectadas mediante una red Host-Only.

💡 Nota para el docente

Se usará Microsoft Print to PDF como impresora simulada ya que está disponible de forma nativa en Windows 10 sin necesidad de hardware físico. Esto permite replicar fielmente el proceso de instalación, compartición y diagnóstico.

⚠️ Antes de empezar

Reemplacen la "X" en ImpresionGrupoX por el número de su grupo. Ejemplo: Grupo 3 → ImpresionGrupo3. Esto evita conflictos en la red.

🧪 Parte 1 — Configurar el servidor de impresión (VM1)

  1. Iniciar VirtualBox y encender la VM1 (servidor). Iniciar sesión como Administrador.
  2. Configurar la IP estática: Panel de Control → Redes → Propiedades → IPv4 → Asignar 192.168.56.10 / 255.255.255.0 / GW: 192.168.56.1.
  3. Verificar el nombre del equipo y grupo de trabajo: Propiedades del Sistema → Nombre de equipo → Cambiar → SERVIDOR-GX, grupo: SOPTEC3.
  4. Ir a Panel de Control → Dispositivos e impresoras → Agregar impresora.
  5. Seleccionar "Microsoft Print to PDF" (o instalar una impresora de la lista si no aparece). Hacer clic en Agregar.
  6. Clic derecho sobre la impresora → Propiedades de impresora → Pestaña Compartir.
  7. Activar: "Compartir esta impresora" → Asignar nombre: ImpresionGrupoX. Aplicar.
  8. Ir a Centro de redes y recursos compartidos → Cambiar configuración de uso compartido avanzado → Activar: "Activar compartir archivos e impresoras".
  9. Verificar que el firewall permite SMB: Windows Defender Firewall → Permitir aplicación → Compartir archivos e impresoras → Habilitar.
  10. 📷 Captura 1: Impresora compartida en "Dispositivos e impresoras" con ícono de mano de compartición.

💻 Parte 2 — Conectar el cliente (VM2)

  1. Iniciar VM2 (cliente). Configurar IP: 192.168.56.11 / 255.255.255.0 / GW: 192.168.56.1.
  2. Nombre del equipo: CLIENTE-GX, grupo de trabajo: SOPTEC3. Reiniciar si es necesario.
  3. Verificar conectividad: abrir CMD y ejecutar: ping 192.168.56.10. Deben recibir respuesta.
  4. Si el ping falla: revisar que ambas VMs usen el mismo adaptador Host-Only y que el firewall del servidor no bloquee ICMP.
  5. Abrir el Ejecutar (Win+R) y escribir: \\192.168.56.10\ImpresionGrupoX → Enter.
  6. Windows instalará automáticamente el driver desde el servidor. Confirmar si se solicitan credenciales.
  7. Verificar que la impresora aparezca en Dispositivos e impresoras del cliente.
  8. Hacer clic derecho → Establecer como predeterminada.
  9. Clic derecho → Ver qué se está imprimiendo → Impresora → Imprimir página de prueba.
  10. 📷 Captura 2: Página de prueba impresa (PDF guardado) desde VM2 con nombre del grupo visible.

🚨 Parte 3 — Diagnóstico de falla simulada

El docente (o el grupo) detendrá el servicio Spooler de impresión en VM1 para simular una falla real.

  1. En VM1: Abrir Servicios (services.msc) → Buscar "Cola de impresión" (Print Spooler) → Clic derecho → Detener.
  2. Desde VM2: Intentar imprimir una página de prueba. ¿Qué mensaje de error aparece?
  3. 📷 Captura 3: Pantalla del error de impresión en VM2.
  4. Diagnosticar: Describir por escrito qué causó el error y por qué afecta al cliente.
  5. Resolver: En VM1, volver a services.msc → Cola de impresión → Iniciar.
  6. Desde VM2: intentar imprimir de nuevo. Confirmar que funciona.
  7. 📷 Captura 4: Servicio Spooler activo y página de prueba exitosa.
  8. Investigar: ¿Qué otros servicios deben estar activos para que la impresión en red funcione? Listarlos.
⚠️ Escenario adicional (si terminan antes)

Agreguen un segundo usuario en VM2 sin privilegios de administrador. Comprueben si puede imprimir. ¿Qué permisos se requieren para imprimir en una impresora compartida?
