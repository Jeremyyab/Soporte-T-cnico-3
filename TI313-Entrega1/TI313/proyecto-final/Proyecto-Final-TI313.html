📌 Descripción del proyecto

🏢 Escenario empresarial

La empresa ficticia DataTec S.A. necesita configurar un equipo de cómputo para su oficina central. El equipo técnico (su grupo) será responsable de configurar completamente un sistema Windows 10 usando VirtualBox, cumpliendo los siguientes requerimientos de la empresa:

  • 3 usuarios con roles diferentes: Administrador, Estándar e Invitado
  • Impresora compartida en red para todos los usuarios
  • Disco adicional configurado para almacenamiento de datos
  • Red cableada configurada con IP estática
  • Red inalámbrica configurada y documentada
  • Acceso remoto habilitado (RDP)
  • Plan de mantenimiento preventivo documentado
  • Copia de seguridad configurada y verificada
💡 Nota importante

Todo el trabajo se hace en VirtualBox. No se requiere hardware adicional. Las configuraciones deben ser funcionales y estar documentadas con capturas de pantalla en cada paso.

📅 Cronograma de avance

📆 Plan de trabajo por semana

1
Semana 1 — Impresoras (9 horas extra clase)
Crear la VM principal con Windows 10. Instalar y compartir una impresora virtual en red. Configurar grupo de trabajo. Conectar una segunda VM como cliente e imprimir desde ella. Documentar configuración completa con capturas.
2
Semana 2 — Virtualización, SO y nube (10 horas extra clase)
Agregar un disco virtual a la VM y configurarlo. Verificar la secuencia de arranque. Documentar características del SO instalado. Explorar aplicaciones de cloud computing disponibles. Instalar actualizaciones pendientes del sistema.
3
Semana 3 — Windows y Redes (10 horas extra clase)
Configurar Panel de Control completo. Crear los 3 usuarios con sus permisos. Configurar red cableada (IP estática) e inalámbrica (documentar pasos aunque sea virtual). Habilitar y probar RDP (Escritorio Remoto). Ejecutar comandos CLI del sistema. Configurar recursos compartidos locales.
4
Semana 4 — Mantenimiento + Entrega (en clase)
Documentar el plan de mantenimiento preventivo. Configurar copia de seguridad y restauración. Finalizar el informe técnico. Defensa oral en clase: cada grupo presenta su VM configurada y explica las decisiones técnicas.
🛠️ Requerimientos técnicos por módulo

🖨️ Módulo 1 — Tecnologías de impresión

  • Instalar impresora: Microsoft Print to PDF compartida en red con nombre ImpGrupoX
  • Configurar permisos: Solo el usuario Administrador puede gestionar la cola de impresión
  • Cliente conectado: Segunda VM conectada exitosamente a la impresora del servidor
  • Página de prueba: PDF generado desde el cliente como evidencia de funcionamiento
  • Diagnóstico documentado: Descripción de al menos 2 problemas de impresión y sus soluciones

☁️ Módulo 2 — Virtualización y SO

  • VM configurada: Windows 10 con al menos 2GB RAM, 40GB disco, adaptadores de red correctos
  • Disco adicional: Agregar un disco virtual de 20GB, inicializarlo y formatearlo en NTFS como unidad D:
  • Secuencia de arranque: Documentar el orden de arranque de la VM (Boot Order en VirtualBox)
  • Actualizaciones: Captura del historial de Windows Update mostrando sistema actualizado
  • Cloud: Documentar 3 servicios cloud que usaría esta empresa y por qué (OneDrive, Teams, Azure AD)

🪟 Módulo 3 — Sistema operativo Windows

  • Panel de Control: Configurar fecha/hora, región, idioma, sonido y energía. Capturas de cada uno.
  • Usuarios creados: AdminDataTec (Admin), UsuarioEst (Estándar), Visitante (Invitado) con contraseñas
  • Administración de discos: Captura de Administración de discos mostrando C: (sistema) y D: (datos)
  • Apps instaladas: Instalar 2 aplicaciones gratuitas y documentar el proceso
  • CLI documentado: Ejecutar y capturar: ipconfig /all, netstat -an, diskpart list disk, tasklist

🌐 Módulo 4 — Redes de Windows

  • Red cableada: IP estática configurada: IP, máscara, gateway, DNS. Captura de propiedades IPv4.
  • Recurso compartido: Carpeta DatosEmpresa compartida con permisos diferenciados por usuario
  • Red inalámbrica: Documentar los pasos para conectar a una red Wi-Fi en Windows 10 (capturas del proceso)
  • Escritorio remoto: Habilitar RDP, configurar usuarios con acceso y documentar cómo conectarse
  • Conectividad: Captura de ping entre las dos VMs y al gateway

🔧 Módulo 5 — Mantenimiento preventivo

  • Plan de mantenimiento: Tabla con actividades diarias, semanales, mensuales y anuales del SO
  • Copia de seguridad: Configurar Historial de archivos en unidad D: y verificar que funciona
  • Punto de restauración: Crear un punto de restauración del sistema y documentar cómo revertirlo
  • Limpieza de disco: Ejecutar Liberador de espacio en disco y capturar resultado
  • Desfragmentación: Ejecutar Optimizar unidades y documentar el resultado
  • Antivirus: Verificar estado de Windows Defender y configurar escaneo programado

🎤 Defensa oral — Semana 4

Cada grupo tiene 10 minutos para presentar su proyecto funcionando en VirtualBox.

¿Qué deben mostrar?

  • VM encendida con Windows 10 configurado
  • Los 3 usuarios creados
  • Impresora compartida funcional
  • Unidad D: con datos
  • Conexión RDP activa
  • Plan de mantenimiento en pantalla

Preguntas de la defensa

  • ¿Qué decisión técnica fue la más difícil? ¿Por qué?
  • ¿Cómo resolverían si el disco falla?
  • ¿Qué seguridad adicional agregarían?
  • ¿Cómo escalarían esto a 50 usuarios?
⚠️ Importante para la defensa

Todos los integrantes del grupo deben poder responder preguntas técnicas. La nota individual puede diferir de la grupal según la participación en la defensa.
